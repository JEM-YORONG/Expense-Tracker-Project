# Expense Tracker Mobile

A React Native expense tracking app built with Expo and SQLite.

## Get Started

1. Install dependencies
   ```bash
   npm install
   ```

2. Start the development server
   ```bash
   npm start
   ```

3. Run on your device
   - Scan QR code with Expo Go (Android/iOS)
   - Or run `npm run android` / `npm run ios` for simulators

## Default Login

- **Admin**: `admin@ExpenseTracker.com` / `admin123`

After first login, admin is saved to SQLite database. Use Admin screen to manage users.

## Features

- Budget management
- Transaction tracking (add/edit/delete)
- Spending analytics
- Admin user management
- Local SQLite storage

See `docs/dev-guide.md` for detailed documentation.
